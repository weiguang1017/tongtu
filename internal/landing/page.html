如何安装

一键安装(Linux / macOS)

curl -fsSL https://raw.githubusercontent.com/weiguang1017/tongtu/main/install.sh | sh

脚本自动识别系统与架构,校验 SHA256 后安装到 /usr/local/bin。 Windows 用户到 Releases 下载解压即可。

启动图形界面

tongtu

自动打开浏览器管理面板,三步向导引导完成配置:粘贴 Cloudflare API Token → 选择域名 → 填写本地服务地址。

一键启动隧道

点「启动连接器」,几秒后即可通过 https://应用名.你的域名.com 访问本地服务。 偏好命令行也有完整子命令:tongtu app add … && tongtu run。
