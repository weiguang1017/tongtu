添加凭证

在 Cloudflare 控制台 → API 令牌,点「创建令牌」→ 最下方「自定义令牌 · 开始使用」,在「权限」区加两行:
  1. 第一个下拉选 Account(账户)→ 第二个选 Cloudflare Tunnel(新版可能显示为 Argo Tunnel (Legacy),是同一个)→ 第三个选 Edit
  2. 点「+ 添加更多」→ 第一个下拉选 Zone(区域)→ 第二个选 DNS → 第三个选 Edit
    别选成 DNS Settings / DNS Firewall / DNS View,只选纯 DNS 才能写记录
  3. 下方「区域资源」选你要用的域名(或所有区域)→ 创建 → 复制令牌粘到下面
用户令牌(cfut_)和账户令牌(cfat_)都支持。

下载设置

若自动下载 cloudflared 时连接 GitHub 失败(国内网络常见),可在此填写本机代理, 通途下载连接器时会走该代理。留空则不使用代理(仍会读取系统 HTTP(S)_PROXY 环境变量)。
常见代理端口:Clash 7890 · V2rayN 10809 · Shadowsocks 1080。 填好保存后,回到概览点「一键安装」即走代理下载。

欢迎使用通途

三步把本地服务发布到公网:① 添加 Cloudflare 凭证 → ② 选择域名 → ③ 映射本地端口。

去 Cloudflare 控制台 → API 令牌,点「创建令牌」→ 最下方「自定义令牌 · 开始使用」,在「权限」区加两行:
  1. 第一个下拉选 Account(账户)→ 第二个选 Cloudflare Tunnel(新版显示为 Argo Tunnel (Legacy),同一个)→ 第三个选 Edit
  2. 点「+ 添加更多」→ 第一个下拉选 Zone(区域)→ 第二个选 DNS → 第三个选 Edit
    别选成 DNS Settings / DNS Firewall / DNS View,只选纯 DNS
  3. 下方「区域资源」选你的域名 → 创建 → 复制令牌(cfut_ 或 cfat_ 开头)粘到下面
选择要使用的根域名(须已托管在 Cloudflare)。
